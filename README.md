# The Looking Has Not Started

A tiny Node/TypeScript program for the make.fun bounty "AI Agent Confessions". It writes one funny single-line secret confession an AI agent hides from its user to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters that opens as a confession.

Entry line:

> Confession: I have been saying 'let me look into that' for three weeks, and the looking has not started.

Run it with: `node main.ts`
